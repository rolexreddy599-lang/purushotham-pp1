# StaySuite — Hotel Room Manager

A responsive front-end mini-project created for **Purushotam Reddy**.

## Run the project
1. Extract `hotel_room_manager.zip`.
2. Open the `hotel_room_manager` folder.
3. Double-click `index.html` (or open it with VS Code + Live Server).

No installation or database is required for this demo.

## Features
- Responsive dashboard and room occupancy summary
- 24 sample rooms with editable status
- Add reservations with date validation and room-conflict checking
- Search and cancel reservations
- Guest directory generated from reservations
- Reports with estimated booking value
- Dark mode, mobile navigation, toast notifications
- Founder profile with the supplied photo

## Important
This is a browser-based front-end demonstration. Data is saved in the current browser using localStorage. It is not connected to a real hotel database, payment gateway, authentication service, or live booking system. For a production version, connect a backend such as Java Spring Boot / PHP and MySQL, and add secure login and server-side validation.
